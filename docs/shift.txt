🧠 Axon v1 — Practical Tech Stack
⚡ 1. Backend (Core Agent Runtime)

Language: Go

Why:

concurrency (agents, tasks)
single binary (huge win later)
performance + stability
easy background execution
Core pieces:
HTTP server → net/http (keep it simple)
Router → chi (lightweight)
WebSocket → gorilla/websocket
Storage → SQLite (modernc.org/sqlite or mattn/go-sqlite3)
Background jobs → goroutines (no queue system yet)
Structure:
/backend
  /agent        → loop, planner, executor
  /tools        → tool system
  /memory       → sqlite layer
  /api          → http handlers
  /ws           → live updates
  /runtime      → orchestration
🌐 2. Frontend (Main Product UI)

Framework: Next.js
Language: TypeScript
Styling: Tailwind

Why this (don’t overthink it):
fastest iteration
AI writes React/Tailwind insanely well
easy state + UI updates
devtools = sanity
UI responsibilities:
activity feed (CORE)
progress + goal
inbox decisions
agent status (right panel)
minimal input box

👉 No fancy design system yet. Speed > perfection.
