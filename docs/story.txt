The Agent System
Five specialized agents running simultaneously. Each with its own model config, tool access, personality, resource limits. Shared memory. Independent execution.
Planner — the brain. Strategic planning, goal alignment, loop orchestration. Runs every 30 minutes. Uses the most capable model available. Sees everything, acts on the big picture.
Growth — volume. Content generation, posting, audience building. Runs continuously. Uses the cheapest fast model — Kimi K2, Gemini Flash — because it's doing high-volume work that doesn't need deep reasoning.
Closer — money. Outreach, follow-up, relationship management. Handles the emails, the replies, the invoices. Uses a capable model because the words matter.
Builder — product. Code generation, UI building, deployment. Runs on-demand. Uses the best model available because quality matters when you're shipping.
Watcher — awareness. Competitor intel, market signals, pivot detection. Runs quietly in the background at near-zero cost. Always on. Never loud unless it finds something worth flagging.

Built-in tools cover email, content, lead generation, code and UI building, deployment, payments across 12 regional processors, and intelligence gathering. But the real power is what happens when a built-in tool doesn't exist.

## The Loop Engine

Loops are the business logic layer. Repeatable workflows the agent executes on schedule or continuously.

**Lead Loop:** find leads → qualify → enrich → draft personalized email → send → wait 3 days → follow up → wait 7 days → follow up again → positive reply → notify founder.

**Growth Loop:** analyze last 7 days of content performance → generate content informed by what worked → post at optimal window → track engagement → update memory.

**Build Loop:** read spec → generate code → test and auto-fix → build UI → judge quality on 5 dimensions → iterate until score hits 7.5/10 → deploy to preview → notify founder with 2-3 specific questions.

**Competitor Intel Loop:** fetch competitor URLs daily → extract pricing, features, copy, job postings → compare to previous snapshot → flag changes → include in morning briefing if significant.

**Agency Sniper Loop (Full Access):** find local businesses via Maps → qualify by social media weakness → enrich with decision maker contact → draft personalized pitch → send → positive reply → draft proposal → proposal accepted → create invoice.

Loops are composable. Custom loops are YAML definitions that chain any tools in any sequence with any trigger condition.

## Memory

Three layers.

**Operational Memory** (SQLite, always on) — complete audit trail. Every action. Every result. Every decision. Every metric at every point in time. The foundation of all learning.

**Semantic Memory** (LanceDB, optional) — vector embeddings of past decisions, content, insights, customer conversations. RAG over your entire company history. The agent can query what worked last time for this exact situation and get real context back.

**Learned Patterns** (extracted continuously) — after every batch of actions, the Learner runs pattern extraction:
```
learned: tuesday emails → 23% higher open rate for this list
learned: maps leads → 2.1x better conversion than scraped leads
learned: price objections spike when leading with features
learned: users skipping week 3 → 89% churn by day 47
```

Not generic advice. Not swarm averages. YOUR patterns. YOUR business. YOUR data. After 90 days the agent knows your business better than any human advisor could. That knowledge is irreplaceable. Leaving means losing it forever.

## The UI Review System

The agent builds, evaluates, and iterates on product UI without the founder touching code.

Playwright takes a screenshot. A vision model evaluates it on five dimensions — visual hierarchy, trust, conversion, craft, mobile. Technical issues get fixed automatically. Subjective decisions surface to the founder as maximum three questions in plain English.

Design references work too. Drop a Figma link, a screenshot, a URL of a site you like. The agent extracts design tokens — colors, typography, spacing, border radius — and generates UI that matches the aesthetic. Diffs against the reference. Iterates until the similarity score is acceptable.

The no-IDE experience: you describe or show what you want, the agent builds it, fixes the obvious issues, shows you a preview with two or three questions, you answer in plain English, it ships.

You never open VS Code. You never look at code. The code exists. You just don't have to.
